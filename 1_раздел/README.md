# Раздел 1: HTTP status checker

Скрипт выполняет 5 запросов к `https://httpstat.us` и обрабатывает ответы по диапазонам HTTP-кодов:

- `1xx`, `2xx`, `3xx` логируются в консоль вместе со статус-кодом и телом ответа.
- `4xx`, `5xx` приводят к генерации `HttpStatusError`; исключение перехватывается в основном цикле и логируется, чтобы скрипт продолжил выполнение остальных запросов.

Запуск:

```bash
python3 script.py
```

Для Windows можно использовать:

```powershell
py .\script.py
```
